# Research Code Showcase

These are samples of the programming work I've done for various physics and astronomy research projects! They are grouped by project:
- **Star Formation** project at UT: determining outflow position and opening angles for protostellar outflows, and identifying physical trends
- **High-Velocity Cloud (HVC)** project at my REU at Green Bank Observatory: analyzing the neutral hydrogen bridge between M31 and M33, its cloud properties, and possible origins

Due to the nature of astronomical data, this does **not** include all the used data or software dependencies required to fully run these programs. However, some sample output is included, and some functions and scripts can be run as-is.

Plot-heavy scripts (such as `HVC_project/cloudPlots.py`) may be better run as a Jupyter notebook.
